# No Swipe

No Swipe 是一个面向抖音推荐流测试的本地 Codex 插件，内置 `douyin-recommendation-rpa` skill。

它覆盖推荐流相关性判断、自然停留与跳过、可复现的互动配额计划、SQLite/CSV 增量保存、断点恢复、质量检查，以及中文字段 Excel 交付。

## 安全边界

- 仅使用用户已打开且已登录的推荐流页面。
- 不绕过验证码、限流、登录或访问限制。
- 评论、关注等外部动作必须获得当次明确授权。
- 默认不进入作者主页；只有用户明确要求抽样时，才查看公开简介或标签并立即返回推荐流。
- 计划动作与实际成功结果分开记录，不用配额计划冒充真实结果。
